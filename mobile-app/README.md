# Hamboi Mindcare Mobile App

A React Native mobile app for mental health support built with Expo.

## Features

- AI-powered chat support
- Crisis hotlines and resources
- Mental health information
- 24/7 availability
- Completely private and secure

## Setup

1. Install dependencies:
\`\`\`bash
npm install
\`\`\`

2. Start the development server:
\`\`\`bash
npm start
\`\`\`

3. Run on Android:
\`\`\`bash
npm run android
\`\`\`

4. Run on iOS:
\`\`\`bash
npm run ios
\`\`\`

## Building for Production

### Android (Play Store)

1. Build APK/AAB:
\`\`\`bash
expo build:android
\`\`\`

2. Follow the prompts to configure your app signing

3. Download the APK/AAB file when complete

4. Upload to Google Play Console

### iOS (App Store)

1. Build IPA:
\`\`\`bash
expo build:ios
\`\`\`

2. Follow the prompts to configure your certificates

3. Download the IPA file when complete

4. Upload to App Store Connect

## Environment

The app connects to your web API at:
`https://v0-hamboi-ai-landing-page-7e7t-ge0ebg3mq.vercel.app`

To change this, edit `app.json` under `expo.extra.apiUrl`

## Publishing

To publish updates over-the-air:
\`\`\`bash
expo publish
\`\`\`
